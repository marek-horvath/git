Git deň 2 - praktické úlohy

Úlohy nadväzujú na stav po prvom dni: každý má vlastné GitHub repository, SSH kľúč, lokálny clone a v ňom tvoje HTML úlohy. Riešenia sú skryté pod zadaniami.

Úlohy

Spoločný príbeh

Pracujete na malom repository pre školenie: máte v ňom HTML úlohy a postupne z neho spravíte jednoduchý „Git workshop kit“. Budete pridávať program dňa, checklist, changelog, release notes, feature branches, conflicts, remote zmeny, tag a rebase.

Prikazy su pisane pre Git Bash. V rieseniach pouzivam branch main. Ak ma niekto master, nahradi v prikazoch main za master.

1. Priprav repository na deň 2

20 minstatus / pull / čistý štart

Otvor svoj lokálny clone z prvého dňa. Over, že si napojený na GitHub cez origin, stiahni posledný stav a priprav priečinok den2 so súborom README.md.

Riešenie 
pwd
ls -a
git status
git remote -v

git checkout main
echo main

git pull origin main

mkdir -p den2
echo "# Den 2" > den2/README.md
echo "" >> den2/README.md
echo "Tu budu materialy a zmeny z druheho dna." >> den2/README.md

git status
git add den2/README.md
git commit -m "feat: prepare day 2 workspace"
git push origin main

2. Nový feature branch pre program školenia

25 minbranch / commit / push

Vytvor branch feature/day2-program. Na branchi pridaj súbor den2/program.md s krátkym programom druhého dňa a pushni branch na GitHub.

Riešenie 
git checkout -b feature/day2-program

echo "# Program dna 2" > den2/program.md
echo "" >> den2/program.md
echo "- Branches" >> den2/program.md
echo "- Merge" >> den2/program.md
echo "- Merge conflict" >> den2/program.md
echo "- Remote repository" >> den2/program.md
echo "- Stash" >> den2/program.md
echo "- Tag" >> den2/program.md
echo "- Rebase" >> den2/program.md

git status
git add den2/program.md
git commit -m "feat: add day 2 program"
git push -u origin feature/day2-program

git log --oneline --graph --all --decorate --max-count=12

3. Prepínanie medzi branches bez chaosu

20 mincheckout / branch

Ukáž, že súbor vytvorený na feature branchi nie je automaticky na hlavnom branchi. Prejdi z feature branchu na hlavný branch a späť. Sleduj, ako sa mení obsah working tree.

Riešenie 
git branch
ls den2

git checkout main
ls den2
git log --oneline --graph --all --decorate --max-count=12

git checkout feature/day2-program
ls den2
cat den2/program.md

git checkout main

Ak bol branch už merged, súbor môže byť viditeľný aj na hlavnom branchi. Vtedy pointa nie je zmiznutie súboru, ale to, že checkout prepína stav working tree podľa branchu.

4. Merge feature branchu do hlavného branchu

20 minmerge

Predstav si, že program dňa 2 je hotový. Mergni feature/day2-program do hlavného branchu, pošli výsledok na GitHub a lokálny feature branch uprac.

Riešenie 
git checkout main
git merge feature/day2-program --no-edit

git log --oneline --graph --all --decorate --max-count=15
git status

git push origin main
git branch -d feature/day2-program

5. Zámerný merge conflict v programe

30 minmerge conflict

Vytvor conflict v súbore den2/program.md. Na feature branchi zmeň riadok so stashom na jednu verziu. Na hlavnom branchi zmeň ten istý riadok na inú verziu. Potom skús merge.

Riešenie 
git checkout main

git checkout -b feature/program-conflict
# otvor den2/program.md a riadok "- Stash" prepis na "- Stash pre rozrobenu pracu"
git diff
git add den2/program.md
git commit -m "feat: describe stash in feature"

git checkout main
# otvor den2/program.md a riadok "- Stash" prepis na "- Stash pocas hotfixu"
git diff
git add den2/program.md
git commit -m "feat: describe stash in main"

git merge feature/program-conflict

Merge má skončiť conflictom.

git status
cat den2/program.md

6. Vyrieš conflict a dokonči merge

25 minconflict markers / add / commit

V súbore den2/program.md odstráň conflict markers a nechaj finálnu verziu riadku tak, aby dávala zmysel pre školenie.

Riešenie

Riadok môže vyzerať napríklad takto:

- Stash pre rozrobenu pracu pocas hotfixu

Potom dokonči merge:

git status
git add den2/program.md
git commit -m "merge: resolve program stash conflict"

git log --oneline --graph --all --decorate --max-count=18
git branch -d feature/program-conflict
git push origin main

7. Stash počas rozrobenej práce

25 minstash / hotfix

Začni upravovať den2/program.md, ale necommituj. Potom si predstav, že musíš rýchlo spraviť hotfix v inom súbore. Odlož rozrobenú prácu cez stash, sprav hotfix a potom sa k práci vráť.

Riešenie 
echo "" >> den2/program.md
echo "Poznamka: po rebase si pozrieme graf historie." >> den2/program.md
git status
git diff

git stash push -m "WIP program notes"
git status
git stash list

git checkout -b hotfix/readme-typo
echo "" >> den2/README.md
echo "Hotfix: doplnene po prvom dni." >> den2/README.md
git add den2/README.md
git commit -m "fix: update day 2 readme"

git checkout main
git merge hotfix/readme-typo --no-edit
git branch -d hotfix/readme-typo

git stash pop
git diff
git add den2/program.md
git commit -m "feat: add rebase note to program"
git push origin main

8. Druhý clone ako simulácia kolegu

30 minclone / fetch / pull

Vytvor druhý clone svojho GitHub repository do vedľajšieho priečinka. Bude sa správať ako kolega alebo druhý počítač. V druhom clone urob commit a push. V pôvodnom clone použi najprv fetch, potom pull.

Riešenie 
pwd
git remote -v

cd ..
git clone git@github.com:tvoje-meno/tvoje-repo.git kolega-copy

cd kolega-copy
echo "Toto pridal druhy clone." > den2/kolega.md
git add den2/kolega.md
git commit -m "feat: add colleague note"
git push origin main

cd ..
cd povodny-clone
git fetch origin
git log --oneline --graph --all --decorate --max-count=20
git pull origin main
ls den2

9. Odmietnutý push, lebo remote je ďalej

30 minpush rejected / pull

V druhom clone pushni jednu zmenu. V pôvodnom clone bez pullu sprav inú zmenu a skús push. Potom situáciu vyrieš cez pull --no-rebase a znovu push.

Riešenie 
cd ..
cd kolega-copy
echo "Remote zmena pred mojim pushom." > den2/remote-first.md
git add den2/remote-first.md
git commit -m "feat: add remote first note"
git push origin main

cd ..
cd povodny-clone
echo "Lokalna zmena bez pullu." > den2/local-after-remote.md
git add den2/local-after-remote.md
git commit -m "feat: add local note after remote changed"

git push origin main
git pull --no-rebase origin main
git push origin main

git log --oneline --graph --all --decorate --max-count=25

10. Remote branch vytvorený v druhom clone

30 minremote branch / upstream

V druhom clone vytvor branch feature/remote-checklist, pridaj checklist a pushni branch. V pôvodnom clone si branch stiahni, pozri ho, mergni do hlavného branchu a remote branch vymaž.

Riešenie 
cd ..
cd kolega-copy
git pull origin main
git checkout -b feature/remote-checklist

echo "# Checklist" > den2/checklist.md
echo "" >> den2/checklist.md
echo "- status" >> den2/checklist.md
echo "- diff" >> den2/checklist.md
echo "- commit" >> den2/checklist.md
echo "- push" >> den2/checklist.md
echo "- pull" >> den2/checklist.md
git add den2/checklist.md
git commit -m "feat: add remote checklist"
git push -u origin feature/remote-checklist

cd ..
cd povodny-clone
git fetch origin
git branch -a
git checkout feature/remote-checklist
cat den2/checklist.md

git checkout main
git merge feature/remote-checklist --no-edit
git push origin main

git push origin --delete feature/remote-checklist
git branch -d feature/remote-checklist

11. Tag release verzie školenia

20 mintag

Predstav si, že aktuálny stav je hotová verzia materiálov po druhom dni. Vytvor jednoduchý tag aj annotated tag a pushni ich na GitHub.

Riešenie 
git checkout main
git pull origin main

git tag den2-v1
git tag
git show den2-v1 --stat

git tag -a den2-v1-notes -m "Den 2 hotovy workshop kit"
git show den2-v1-notes --stat

git push origin den2-v1
git push origin den2-v1-notes

12. Rebase lokálneho feature branchu

35 minrebase

Vytvor lokálny branch feature/rebase-cleanup, sprav na ňom dva commity. Potom sa vráť na hlavný branch, pridaj tam nový commit a feature branch prelož cez rebase na nový základ. Branch pred rebase nepushuj.

Riešenie 
git checkout main
git pull origin main

git checkout -b feature/rebase-cleanup
echo "rebase krok 1" > den2/rebase-demo.md
git add den2/rebase-demo.md
git commit -m "feat: add rebase demo"

echo "rebase krok 2" >> den2/rebase-demo.md
git add den2/rebase-demo.md
git commit -m "feat: extend rebase demo"

git checkout main
echo "Novy zaklad pre rebase." > den2/base-after-feature.md
git add den2/base-after-feature.md
git commit -m "feat: add new base before rebase"

git log --oneline --graph --all --decorate --max-count=25

git checkout feature/rebase-cleanup
git rebase main
git log --oneline --graph --all --decorate --max-count=25

git checkout main
git merge feature/rebase-cleanup --ff-only
git branch -d feature/rebase-cleanup
git push origin main

Rebase sa tu robí iba na lokálnom branchi, ktorý ešte nebol zdieľaný.

13. Detached HEAD a záchrana práce

30 mindetached HEAD

Choď na starší commit cez HEAD~3, sprav tam commit a zachráň ho vytvorením nového branchu. Potom ho mergni späť do hlavného branchu.

Riešenie 
git checkout main
git log --oneline --decorate --max-count=10

git checkout HEAD~3
git status

echo "Toto vzniklo v detached HEAD." > den2/detached-demo.md
git add den2/detached-demo.md
git commit -m "demo: commit in detached HEAD"

git log --oneline --decorate --max-count=5
git switch -c rescue/detached-demo

git checkout main
git merge rescue/detached-demo --no-edit
git branch -d rescue/detached-demo
git push origin main

14. Záverečný changelog a release notes

30 minsummary / log / show

Na konci vytvor CHANGELOG.md a den2/release-notes.md. Použi git log a git show, aby si vedel, čo sa počas dňa stalo. Potom všetko commitni a pushni.

Riešenie 
git checkout main
git status
git log --oneline --graph --all --decorate --max-count=30

echo "# Changelog" > CHANGELOG.md
echo "" >> CHANGELOG.md
echo "## Den 2" >> CHANGELOG.md
echo "" >> CHANGELOG.md
echo "- pridany program" >> CHANGELOG.md
echo "- vyrieseny merge conflict" >> CHANGELOG.md
echo "- vyskusany stash" >> CHANGELOG.md
echo "- vyskusany remote workflow" >> CHANGELOG.md
echo "- pridane tags" >> CHANGELOG.md
echo "- vyskusany rebase" >> CHANGELOG.md

echo "# Release notes" > den2/release-notes.md
echo "" >> den2/release-notes.md
echo "Materialy po druhom dni su pripravene ako demo Git workflow." >> den2/release-notes.md

git diff
git add CHANGELOG.md den2/release-notes.md
git diff --staged
git commit -m "docs: add day 2 changelog and release notes"
git push origin main

git log --oneline --graph --all --decorate --max-count=30
git show HEAD --stat
Úlohy sú postavené tak, aby účastníci používali svoje reálne GitHub repository a zároveň si nič kritické nepokazili. Každé riešenie je skryté v rozbaľovacom bloku.
