# Git checklist - GitHub Pages

Tento priecinok je hotovy staticky web pre GitHub Pages.

## Ako pouzit

1. Skopiruj obsah tohto priecinka do repository, kde chces mat GitHub Pages.
2. Commitni a pushni zmeny.
3. V GitHub repository chod do `Settings` -> `Pages`.
4. Nastav `Deploy from a branch`.
5. Vyber branch `main` a folder `/root`, ak kopirujes tieto subory priamo do rootu repository.

Hlavny subor webu je `index.html`.
